Pro 与 Flash — 双版本怎么选

同一套 V4 技术路线，两种不同的容量与成本取舍。

V4-Pro 和 V4-Flash 共享混合注意力、mHC、DeepSeekMoE、Muon、MTP 与 1M 上下文；Flash 不是 Pro 的量化版，而是独立训练的较小模型。两者每个 token 都激活 6 个路由专家，但层数、隐藏维度、专家池和注意力配置不同。报告显示，Flash 在增加推理预算后可在不少 reasoning 任务上接近 Pro；Pro 在知识评测和高难度复杂 Agent 任务上更强。

怎么选

如果优先考虑推理计算量，可先选 Flash；它在 1M 场景下的单 token FLOPs 和 KV cache 都低于 Pro，并能通过更高 reasoning effort 缩小部分数学与代码任务的差距。如果任务依赖广泛事实知识，或属于高难度、长流程 Agent 工作，Pro 的评测结果更稳妥。这里不比较 API 价格或实际响应速度，因为技术报告没有给出统一部署条件下的数据。
