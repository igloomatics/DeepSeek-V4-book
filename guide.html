阅读指南 — 学习路线图

不管你是只想知道"V4 改了什么"的研究爱好者，还是要把这套方法搬上自己集群的工程师，都能找到适合自己的学习路径。

全书 20 章 + 两份附录，按"架构 → 基础设施 → 预训练 → 后训练 → 评测"五段铺开。但它不是必须从头读到尾。下面给出 4 条预设路线，每条路线都有目标读者、推荐顺序和大致工时。最后附一张 核心知识图谱，帮你看清章与章之间的依赖关系。

路线一：先看懂"V4 到底改了什么"（推荐入门）

如果你只想用一个下午建立"V4 相对前代的全貌"，按这个顺序读：

摘要与全景（abstract）
  │  目标：5 分钟拿到一张"整体架构 + 关键数字"的小抄
  ▼
Ch01 演进地图（必读）
  │  目标：把 V4 的六条改进主线一次串起来
  ▼
Ch03 mHC ＋ Ch04 CSA（要点速读）
  │  目标：抓住 V4 的两个最重要架构创新
  ▼
附录 A 评测结果（浏览）
  │  目标：看 V4 在闭源旗舰面前的真实排位
  ▼
感兴趣的其他章节

预计时间：4-6 小时（一个下午 + 一晚）。

路线二：长上下文 / 注意力研究

如果你正在做 long-context、稀疏注意力或 KV cache 优化：

Ch01 演进地图（背景，必读）
  │
  ├──► Ch04 CSA — 长上下文的快通道（核心必读）
  │      重点：压缩 KV、Lightning Indexer、top-k 选择
  │
  ├──► Ch05 HCA — 长上下文的全景镜（核心必读）
  │      重点：m'=128 的重压缩、CSA/HCA 交替策略
  │
  ├──► Ch12 推理框架 — KV 的异构调度（重要）
  │      重点：异构 KV 布局、PagedAttention 的局限、prefill 复用
  │
  ├──► Ch11 训练框架 — mHC 的工程脚手架（推荐）
  │      重点：长上下文 CP、Tensor-level Checkpointing
  │
  └──► Ch14 Anticipatory + SwiGLU（推荐）
         重点：4K → 1M 阶梯训练里的稳定性补丁

预计时间：1-2 周。

路线三：MoE 与训练系统

如果你在搭自己的 MoE 训练栈，关心通信、低精度、专家路由：

Ch02 DeepSeekMoE 与 MTP（背景必读）
  │
  ├──► Ch07 MegaMoE — 让 all-to-all 消失（核心必读）
  │      重点：把通信完全藏在计算下面、C/B ≤ 6144 阈值
  │
  ├──► Ch08 TileLang — 写给 GPU 的方言（核心必读）
  │      重点：DSL 替掉成百上千 ATen 算子
  │
  ├──► Ch10 FP4 QAT — 显存的最后一刀（重要）
  │      重点：FP4 量化感知训练实战
  │
  ├──► Ch09 批不变与确定性（重要）
  │      重点：训练-推理一致性
  │
  └──► Ch14 Anticipatory + SwiGLU（推荐）
         重点：负载均衡、loss spike 压制

预计时间：1-2 周。

路线四：后训练 / RL 工程师

如果你在做 SFT / RL / 蒸馏 / Agent，要的是"数据怎么造、目标怎么定、loss 怎么算"：

Ch16 Specialist — 多面手的炼成（核心必读）
  │      重点：双阶段 post-training、GRPO、三档 reasoning effort、GRM
  │
  ├──► Ch18 OPD — 多教师 → 单学生的合一（核心必读）
  │      重点：reverse KL、全词表蒸馏、为什么不用混合 RL
  │
  ├──► Ch19 RL / OPD 工程（重要）
  │      重点：teacher scheduling、preemptible rollout
  │
  ├──► Ch17 Tool 接口三件套（重要）
  │      重点：DSML schema、Interleaved Thinking、Quick Instruction
  │
  ├──► Ch20 DSec — 代码沙箱与安全护城河（推荐）
  │      重点：单集群 10w+ sandbox、四种执行衬底
  │
  └──► 附录 A 真实任务胜率（参考）
         重点：Code Agent 67% pass、内部问卷

预计时间：1 周。

  • 不要按章节号顺序读。Ch01 之后，按上面的路线挑你需要的支线。
  • 遇到符号查不到含义，直接跳到 附录 B 参数速查。
  • 每章右上角的 hover 名词解释（KV cache / FLOPs / FFN 等）能让你不必频繁切窗口查百科。
  • 如果只想看"V4 究竟比 V3.2 强多少"，跳到 附录 A 直接看跑分。
